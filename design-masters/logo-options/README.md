# Bellmont Express logo directions

These are independent vector directions. Cargo B No. 5 is now the live website logo and favicon.

- `01-bell-container.svg`: closest to the current bell idea, simplified and more geometric.
- `02-route-monogram.svg`: a bold B with a route line, strong at small sizes.
- `03-meridian-compass.svg`: premium global-network direction with a meridian and cargo block.
- `04-vessel-badge.svg`: compact app icon and favicon direction.
- `05-cargo-b.svg`: assertive wordmark companion for a modern logistics brand.
- `06-waypoint-mark.svg`: destination and tracking direction, useful for the app icon.
